# Sécurité / Security

## Signaler une vulnérabilité

Ne publiez pas de ticket public. Signalez-la en privé par le signalement de vulnérabilité du
dépôt (onglet « Security », « Report a vulnerability » sur GitHub), avec : la version
concernée, le mode (Poste ou Serveur), les étapes pour reproduire et l'impact constaté. Une
réponse est donnée sous 5 jours ouvrés.

## Report a vulnerability

Do not open a public issue. Report it privately through the vulnerability reporting of the
repository (the "Security" tab, "Report a vulnerability" on GitHub), with: the affected
version, the mode (Desktop or Server), steps to reproduce and the observed impact. You will
get an answer within 5 working days.

## Versions suivies / Supported versions

| Version | Correctifs de sécurité / Security fixes |
|---|---|
| 3.x | Oui / Yes |
| 2.x | Non / No |
| 1.x | Non / No |

Les exigences de sécurité et leurs preuves sont dans `docs/securite.md`.
