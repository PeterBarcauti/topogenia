# Couverture phase 3, porte round 1, correction C3 : tenue sous charge, nettoyage, courses, écritures sans version

Constats traités : Intégrité M1, Sécurité M3, Données m1, Fidélité et Architecture (instabilité sous charge) ;
Intégrité m3 (bases qui peuvent rester), m4 (délais qui masquent une course), m5 (combinaisons de nouvel essai
jamais produites) ; Données m3 (écriture sans version sans verrou). Décisions : ADR 040 (nouvelle), ADR 030
complétée (contrat des enregistrements sans version). Préfixe des tests : `Topogenia.Persistence.Tests.`.
