hors du plan de base), m2 (tri par identifiant) et m3 (`structure_version + 1` sur `int.MaxValue`). Décisions : ADR 038,
complément du round 2 ; ADR 039, une conséquence. Migrations SQL Server `20261023174530_TextGuardsAndIntegerBounds`

(troisième). Préfixe des tests : `Topogenia.Persistence.Tests.`. Les théories tournent sur SQLite et SQL Server. À
reporter dans `docs/couverture.md` : la colonne « Test 2.0 » reçoit les tests ci-dessous en plus de ceux déjà cités.
