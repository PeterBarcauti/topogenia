# Couverture phase 3, fin : lecture cohérente en instantané (ADR 031 révisée)

Lignes touchées par le passage du sérialisable à l'instantané en SQL Server (spec 3.4 : « transaction en lecture
cohérente (instantané en SQL Server, transaction de lecture en SQLite) » ; la spec n'a pas d'identifiant propre pour
cette phrase, portée par A-4-51 et A-5-11). Préfixe des tests de persistance : `Topogenia.Persistence.Tests.` ; les
théories tournent sur SQLite **et** SQL Server, les tests `On_sql_server_...` et la classe
`Schema.SnapshotIsolationTests` sur SQL Server seul (options de base propres à SQL Server ; SQLite n'en a besoin
d'aucune). À reporter dans `docs/couverture.md` : la colonne « Test 2.0 » reçoit les tests ci-dessous (ils
remplacent la remarque « sérialisable en SQL Server »), la colonne « État » la valeur indiquée.
