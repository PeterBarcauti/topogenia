## Ligne A-5-12

Texte de la remarque (colonne « Test 2.0 », entre parenthèses après les trois tests) :

> Règle resserrée sur le texte de la ligne (ADR 031 révisée) : seules `ALTER DATABASE CURRENT SET
> ALLOW_SNAPSHOT_ISOLATION` et `ALTER DATABASE CURRENT SET READ_COMMITTED_SNAPSHOT` sont permises, une option par
> instruction, `ON` ou `OFF` (ou trou d'une chaîne interpolée), au plus `WITH ROLLBACK IMMEDIATE`, puis la fin de
> l'instruction ; tout autre `ALTER DATABASE` (`CURRENT` compris : `TRUSTWORTHY`, `DB_CHAINING`, `MODIFY NAME`,
> `SINGLE_USER`, `ADD FILE`, `ENCRYPTION`, `COLLATE`, `RECOVERY`, seconde option après une virgule), `ALTER DATABASE
> <nom>`, `[CURRENT]`, `SCOPED CONFIGURATION`, `CREATE DATABASE`, `DROP DATABASE`, `sp_getapplock`, `USE master`,
> `master.*` refusés, migrations et sondes comprises. Écart nommé : EF Core lui-même appelle `sp_getapplock` pour le
> verrou des migrations (`IHistoryRepository.AcquireDatabaseLockAsync`, pris par `SchemaMigrations.CheckAsync` et par
> `Database.MigrateAsync`, A-4-35) et crée la base (`CREATE DATABASE` de `Database.MigrateAsync`, compte `db_owner` de
> `--migrate`) : ce n'est pas du code de l'application, la règle lit les sources ; aucun droit sur `master` n'est
> demandé au compte de l'application. Mutations : ancienne expression (les échantillons `TRUSTWORTHY`... passent),
> expression sans la fin d'instruction (la virgule passe).

## Ce qui reste

- Ce que le compte de l'application ne voit pas (déclencheur de base, objet hors des deux schémas sans droit visible,
  droit donné à un utilisateur) n'est refusé qu'à `--migrate` ; proposition au chef de projet : `GRANT VIEW
  DEFINITION TO topogenia_app` (niveau base) par une migration du fournisseur SQL Server (ADR 037, point 6).
- Les migrations écrites à la main n'ont pas encore leur en-tête de deux lignes : la règle
  `Topogenia.Architecture.Tests.FileFormatRulesTests.Every_file_starts_with_its_name_then_a_description` les voit
  désormais et reste rouge jusqu'au report des en-têtes (fichiers de l'agent C2).
