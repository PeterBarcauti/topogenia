# 000 - Arbitrages de la phase 0

## Contexte

Les squelettes de couverture (parties A et B de `couverture.md`) et l'inventaire des tests
(`portage-tests.md`) ont relevé des points que la spécification ne tranche pas, ou que le code
1.x tranche autrement que l'annexe. Règle appliquée (prompt 6.4) : défaut de la spec s'il
existe, sinon comportement le plus proche de la 1.x. Chaque arbitrage est présenté sous la
forme demandée par le prompt 6.4 : contexte, options, choix, raison. Les points qui demandent
l'avis du porteur du projet sont repris dans `questions.md` ; les autres sont des lectures de la spec ou
du code 1.x consignées pour traçabilité.
