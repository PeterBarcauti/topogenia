# Portage P4-T08 : fiches, documents, RACI, scénarios de flux

Lignes de `portage-tests.md` dont la cible nomme `Host.Tests`, pour les fichiers 1.x `DocumentsFluxTests.cs`
(T-DOCF), `FichesTests.cs` d'intégration (T-FICI), `RaciTests.cs` (T-RACI), `ScenariosFluxTests.cs` (T-SCFL),
`FichesTests.cs` unitaires (T-UFIC) et `FichiersTests.cs` (T-FICR).

- Préfixe des tests 2.0 : `Topogenia.Host.Tests.` ; les nouveaux tests sont dans `Ported/`
  (`SheetsAndDocumentsPortedTests`, `DocumentFlowsPortedTests`, `RaciAndFlowsPortedTests`,
  `FlowScenariosPortedTests`, appels communs dans `SheetPortingCalls`). Chaque test est une théorie sur
  `Engines.All` : SQLite en mode Poste, SQL Server en mode Serveur.
- Chaque écriture envoie la version que son client vient de lire (`If-Match` obligatoire en mode Serveur) :
  version du brouillon, de l'étape ou de l'usage, ou `0` quand le client n'a lu aucun enregistrement (ADR 045).
- `FichesTests.cs` (unitaires, T-UFIC-01 à 08) n'a aucune ligne de cible `Host.Tests` (toutes `Domain.Tests`,
  T-UFIC-05 aussi `Interchange.Tests`) : aucune ligne ci-dessous. Les lignes T-FICR appartiennent à
  `FichiersTests.cs` (partie 1) ; elles sont reprises ici parce que la tâche les nomme.
- Bilan : 45 lignes `Host.Tests` (T-DOCF 9, T-FICI 13, T-RACI 7, T-SCFL 7, T-FICR 9). 3 déjà prouvées par un
  test d'hôte existant, 33 prouvées par 33 nouveaux tests (66 cas, 33 par moteur), 9 renvoyées à la phase 5.
