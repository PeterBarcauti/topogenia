# Portage P4-T08 : projets et sécurité, corbeille, traductions, modèle, infrastructure

Lignes de `portage-tests.md` dont la cible 2.0 nomme `Host.Tests` : partie 1, `ProjetsEtSecuriteTests.cs` (T-PSEC),
`CorbeilleTests.cs` (T-CORB), `TraductionsTests.cs` (T-TRAD), `ModeleTests.cs` (T-MODE) ; partie 2,
`InfrastructureTests.cs` (T-UINF). Les lignes sans cible `Host.Tests` (T-MODE-02, 13, 14, T-UINF-01 à 04 et 06 à 13) ne
sont pas reprises ici.

Préfixe des noms de l'hôte : `Topogenia.Host.Tests` ; les tests d'un autre niveau sont nommés en entier. Niveau `Host` : hôte complet en mémoire, matrice SQLite (mode Poste) x
SQL Server (mode Serveur, `If-Match` exigé), HTTP seulement. Niveau `Host, réel` : hôte sur Kestrel (`Desktop/`,
`Server/`). Niveau `Host, unitaire` : classe de l'hôte appelée sans HTTP. Les nouveaux tests sont dans
`tests/Topogenia.Host.Tests/Ported/ProjectsAndSecurity*PortedTests.cs`.

Bilan : 50 lignes ; 14 déjà prouvées par un test de l'hôte existant ; 36 prouvées par 37 nouveaux tests (74 cas avec
les deux bases) ; aucune ne relève de la phase 5. Quelques lignes renvoient en plus une partie de leur intention à un
autre niveau (colonne Remarque).
