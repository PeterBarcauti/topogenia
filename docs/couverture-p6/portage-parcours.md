# Portage des parcours de bout en bout

Les parcours de la 1.x (`43_Outil_Collaboratif/carto/web/e2e/`, lecture seule) : 16 fichiers, 46 tests, dont un joué quatre
fois (`regressions.spec.ts`, essais 1 à 4), soit les 49 parcours de la spécification 11. Chacun est porté avec la même
intention dans `topogenia/web/e2e/`, contre le vrai hôte (ADR 067) : mode Poste sur SQLite par défaut, mode Serveur sur
SQL Server avec `E2E_MODE=server` ; les deux passent. La colonne Remarque dit l’écart avec la 1.x et la décision qui le
justifie.
