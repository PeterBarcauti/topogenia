# À peaufiner en fin de projet

Règle d'économie décidée avec le porteur du projet le 25/10/2026 : pendant la construction, les contrôles se
concentrent sur ce qui trouve de vrais défauts ; tout ce qui est allégé est inscrit ici pour y revenir à la fin
(tâche P7-T07). Chaque entrée dit quoi, où, et pourquoi elle a été remise à plus tard.

## Règles appliquées depuis le 25/10/2026

1. Rounds de porte à partir du round 3 : seuls les mandats qui ont encore un bloquant ou un majeur sont relancés.
2. Mutations : seulement sur les correctifs de logique métier ou de sécurité ; les autres tests sont inscrits ici.
3. Couverture : les lignes `partiel` ne sont plus fermées d'avance ; seules celles qu'un contrôleur relève comme
   majeures le sont. Les autres sont inscrites ici.
4. Mineurs : listés au journal et ici, jamais corrigés par un agent dédié pendant la construction.
